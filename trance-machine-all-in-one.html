🎩 Hi-Hat Pattern Generator

📖 How to Use

Click cells to cycle: Off → Closed Hat → Open Hat → Off

White: Off | Purple: Closed | Red/Cyan: Open

MIDI Notes: Closed = C#1 (42), Open = A#1 (46)

🥁 Snare Pattern Generator

📖 How to Use

Click cells to cycle: Off → Snare → Clap → Ghost Note → Off

White: Off | Purple: Snare | Red: Clap | Pink: Ghost

MIDI Notes: Snare = D1 (38), Clap = D#1 (39), Ghost = D1 low velocity

📖 Setup Required

Windows: Install loopMIDI (free virtual MIDI driver)

Mac: Enable IAC Driver (Audio MIDI Setup → MIDI Studio → IAC Driver)

Ableton: Preferences → MIDI → Enable "Track" input for virtual MIDI port

Then: Create MIDI track in Ableton, set input to virtual port, add drum samples

Click "Play": MIDI streams directly to Ableton in real-time!
