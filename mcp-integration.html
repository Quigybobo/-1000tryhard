🤖 MCP Integration

AI-Assisted Pattern Generation • Natural Language Commands • Claude Desktop

✨ What is MCP Integration?

The Model Context Protocol (MCP) allows AI assistants like Claude to use the Trance Machine Toolkit directly!

Instead of manually opening tools and clicking buttons, you can just talk to Claude and have it generate patterns for you.

💬 Example: Natural Language Pattern Generation

You: "Generate a psytrance drop at 142 BPM in E phrygian dominant and save it to my Ableton project folder"
Claude: I'll generate a complete psytrance drop for you!

[Uses MCP tools to generate]

✅ Generated:
• Psytrance drums (kick + hi-hat + snare) at 142 BPM
• Psytrance bassline in E phrygian dominant at 142 BPM

Files saved to: /Users/you/Music/Ableton/Project/MIDI/
• psytrance-drums-142bpm.mid
• psytrance-bass-Ephrygian-142bpm.mid

Import these MIDI files into Ableton Live and start producing! 🚀

🚀 Setup Instructions

Step 1: Install Dependencies

Navigate to the MCP server directory and install Node.js packages:

cd mcp-server
npm install

Step 2: Configure Claude Desktop

Add the MCP server to your Claude Desktop configuration file:

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json

Windows: %APPDATA%\Claude\claude_desktop_config.json

Edit the config file and add:

{
  "mcpServers": {
    "trance-machine": {
      "command": "node",
      "args": ["/path/to/mcp-server/index.js"]
    }
  }
}

⚠️ Important

Replace /path/to/mcp-server/index.js with the actual full path to the MCP server on your system!

Example: /Users/yourname/Music/-1000tryhard/mcp-server/index.js

Step 3: Restart Claude Desktop

Close and reopen Claude Desktop. The MCP server will automatically connect on startup.

Step 4: Test It!

Open Claude Desktop and try:

"Generate uplifting trance drums at 138 BPM"

Claude will use the MCP server to generate the pattern and return MIDI data!

✅ Success!

You can now generate patterns by just talking to Claude!

🛠️ Available Tools

The MCP server exposes 6 tools that Claude can use:

  1. generate_kick_pattern - Kick drum patterns (5 styles)
  2. generate_hihat_pattern - Hi-hat patterns (6 styles)
  3. generate_snare_pattern - Snare/clap patterns (6 styles)
  4. generate_drumkit_pattern - Complete drum kits (5 genres)
  5. generate_bassline_pattern - Melodic basslines (6 styles, all scales)
  6. generate_full_track - Complete tracks with drums + bassline

See mcp-server/README.md for detailed documentation on each tool.

💡 Pro Tips

Saving Files

By default, Claude returns MIDI data as base64. To automatically save files, specify a path:

"Generate psytrance drums and save to /Users/me/Music/Ableton/Project/MIDI/drums.mid"

Multiple Variations

Ask Claude to generate multiple versions:

"Generate 3 kick patterns: simple, medium, and complex at 138 BPM"

Arrangement Building

Request full arrangements with multiple sections:

"Create a full trance track with:
- Intro drums (simple, 4 bars)
- Verse drums + bassline (medium, 8 bars)
- Build-up (complex fills, 8 bars)
- Drop (full energy, 8 bars)
All at 138 BPM in A minor"

🔧 Troubleshooting

MCP Server Not Connecting

  • Check that Node.js is installed: node --version
  • Verify the path in claude_desktop_config.json is correct
  • Make sure you ran npm install in the mcp-server directory
  • Restart Claude Desktop after config changes

Claude Doesn't Use the Tools

  • Make sure you're using Claude Desktop (not web version)
  • Try being more specific: "Use the trance-machine MCP server to generate..."
  • Check Claude Desktop logs for errors

MIDI Files Not Generating

  • If specifying save paths, ensure the directory exists
  • Check file permissions for the output directory
  • Try requesting base64 output instead (default behavior)
