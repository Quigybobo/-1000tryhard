📖 How to Use

1. Setup Virtual MIDI:

• Windows: Install loopMIDI (free)

• Mac: Enable IAC Driver (built-in): Audio MIDI Setup → MIDI Studio → IAC Driver → Enable

2. Connect Browser to Virtual MIDI:

• Click "Connect MIDI" button above

• Grant MIDI access permission in browser

• Select your virtual MIDI port from dropdown (loopMIDI or IAC Driver)

3. Configure Ableton Live:

• Open Ableton Live → Preferences → Link/Tempo/MIDI

• Enable Track input for your virtual MIDI port (loopMIDI or IAC Driver)

• Create MIDI track, set input to virtual MIDI port

• Add Impulse or drum samples

4. Generate & Play:

• Select pattern styles for kick/hat/snare

• Click grid cells to customize pattern

• Click "Play Pattern" - MIDI sends directly to Ableton!

• No file export needed - real-time MIDI streaming!

⚠️ Requirements

• Browser: Chrome or Edge (best Web MIDI support)

• Virtual MIDI driver: loopMIDI (Windows) or IAC Driver (Mac)

• Ableton Live: Any version (Intro, Standard, Suite)

🎵 MIDI Mapping

• Kick: C1 (MIDI 36)

• Hi-Hat Closed: C#1 (MIDI 42)

• Hi-Hat Open: A#1 (MIDI 46)

• Snare: D1 (MIDI 38)
